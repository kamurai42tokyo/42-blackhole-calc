# Black Hole 逆算 — 42 Tokyo

現在のMilestoneとペース期日から、各ペースの期日とBlack Holeまでの残り日数を逆算します。
依存パッケージなし・ビルド不要の単一HTMLファイルです。

**実際のBlack Holeはこのツールが出す日付より早いと想定してください。**

## 使い方

4つを入力します。

| 入力 | 例 |
|---|---|
| 現在のMilestone | Milestone 3 |
| 現在のペース | ペース22 |
| 現在のペースの期日 | 2026-10-01 |
| 今後取得予定のフリーズ日数 | 0 |

すでに消化したフリーズは入力不要です。期日から逆算する実効kickoffに吸収されます。

## 計算方法

ペース表の各マスは「kickoffからの累積日数」です。したがって入力から実効kickoffを逆算すれば、表の全マスを日付に展開できます。

```js
kickoff = 現在の期日 − PACE[現在のペース][現在のMilestone]
期日(p, m) = kickoff + PACE[p][m] + 今後のフリーズ日数
Black Hole = 期日(24, 現在のMilestone)
```

入学日を知らなくても計算できるのがポイントです。同じMilestoneの2つのペース期日は同じkickoffを共有するので、差を取るとkickoffが消えます。フリーズは全期日を同じ日数だけ後ろへ動かすため、**ペース間の差はフリーズの有無に影響されません**。

ペース番号はコモンコア修了までの月数です。配分は比例ではありません。Milestone 3以降、ペース22とペース24の差は一律60日で固定されています。

## 前提（未検証）

1. **Black Hole = ペース24の期日**。表にこれ以降のペースが存在しないことからの推論で、公式に確認したものではありません。
2. **フリーズ1日 = 期日1日後ろ倒し**。42 APIではフリーズ（Anti-Grav Unit）が `advanced_staff` ロールを要求するため、外部からは検証できません。
3. 表は改定され得ます。

正確な情報は42東京のスタッフに確認してください。

## 公開手順

```bash
git init
git add .
git commit -m "Add black hole calculator"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/42-blackhole-calc.git
git push -u origin main
```

リポジトリの **Settings → Pages → Source** で `main` / `/ (root)` を選ぶと、
`https://<ユーザー名>.github.io/42-blackhole-calc/` で公開されます。

ローカル確認は `python3 -m http.server` でも、`index.html` を直接ブラウザで開くだけでも動きます。

## プライバシー

計算はすべてブラウザ内で完結します。42 APIへの接続も、外部への送信もありません。
